# Nimatoulaye Sow for President

Campaign flyer for Nimatoulaye Sow, Student Council President 2026-2027 at Belmont Prep. The page shows her flyer with a QR code that opens a Google Form where students from every grade can share ideas.

## Set the form link

Open `index.html` and replace the link on this line with the real Google Form link:

```js
const FORM_URL = "https://docs.google.com/forms/d/e/1FAIpQLSejfcUe8Sh3D1j2tmClyxqVa8H0D5NUF0JjXzFsCB_S6RLrlA/viewform";
```

## Files

- `index.html` – builds the flyer and QR code
- `flyer.jpg` – the original flyer
